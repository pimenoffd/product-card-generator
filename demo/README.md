# Сохранённые результаты

`cases.json` содержит два входа, а `results.json` — соответствующие карточки из live-прогона 7 ноября 2026 года. Первый вход восстановлен из демонстрационного примера приложения, второй — из локальной выборки фида для RGK DL70. Технические характеристики манометра взяты из примера ТЗ; для дальномера источник указан в [карточке каталога](https://www.souz-pribor.ru/product/lazernyy-dalnomer-rgk-dl70/) (offer ID 194057).

Обе карточки получены моделью `google/gemini-2.5-flash` с версией промпта 2.0; каждая потребовала две попытки. Повторная генерация выполняется, если первая не прошла автоматические проверки: модель получает исходные данные и замечания. Если после второй попытки замечания остаются, карточка сохраняется со статусом `needs_review`. Для манометра сохранены 706 входных и 600 выходных токенов, длительность 6,509 с; для дальномера — 604 и 239 токенов, 4,130 с. Полные метаданные находятся в `results.json`.

Автоматическая оценка не обнаружила новых чисел или типовых служебных фраз, характеристики сохранены. Оба описания короче требуемых 800–1200 символов: 621 и 104 соответственно. Карточки требуют проверки человеком.

Проверка сохранённых результатов без API:

```bash
python -m product_cards.evaluate --cases demo/cases.json --results demo/results.json --output evals/reports/demo-report.json
```
